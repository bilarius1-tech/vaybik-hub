## Решения

- Ссылки чата — только через `/admin/sso/chat`, не прямые URL manage.
- Атлас — внешние ссылки (не SSO); в реестре EXTERNAL.

- SSO лидов: тот же протокол, что у чата, свой `aud: "leads"` и отдельный секрет.
- Диск хоста для метрик: `/var:/host/disk:ro` + `/proc:/host/proc:ro`, **не** `/:/host/root`.
- Цвета графиков: только resolved hex/rgba из CSS (или fallback темы A), не сырые `var(--…)`.
