## Решения

- Client ≠ Partner; при сбое sync статус хаба не откатываем.
- Dev → chat-test; без env кнопка выкл. + ручной externalId.
- SSO: токен только в Location/redirectUrl; в БД только jti; reauth как Vault.
- Impersonate отдаёт JSON `{redirectUrl}`, не 302 (fetch+manual = opaqueredirect).
- Upsert в чат: UPPERCASE `ACTIVE|PAUSED|EXPIRED|OFF` + даты; null-даты не слать без явного сохранения срока.
- Удаление: бэкап хаба → DELETE в чат → cascade в хабе; иначе `deleteIncomplete`.
