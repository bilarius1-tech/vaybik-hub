# Дизайн-система админки Вайбика

Основа: дашборд **km-dashboard** («Первый километр», https://ztim2008.github.io/km-dashboard/), исходники: `bilarius1-tech/km-dashboard` (`index.html`, `style.css`, `app.js`).
Задача: **сохранить внешний вид km-dashboard** (тёмная тема, сайдбар, карточки с градиентом, KPI с полоской, таблицы, «пилюли», инсайты, калькуляторы) и перекрасить акцент под бренд Вайбика.

## 2. Токены (оригинал → Вайбик)

Оригинал km-dashboard (синий акцент):

```css
--bg:#0a0f1e; --bg2:#0e1528; --card:#121a30; --card2:#182142; --bd:#253156; --bd2:#31406d;
--tx:#e8ecf8; --mu:#9aa5c3; --ac:#2f6bff;
--gr:#22c55e; --rd:#ef4444; --yl:#f5b041; --vi:#a78bfa; --cy:#06b6d4; --pk:#ec4899;
--rowline:#202b4d; --insbg:#182649; --insbd:#31508c;
```

Бренд Вайбика (с сайта vaybik.ru): фон `#0e0c0a`, текст `#fff8f2`, muted `#c4b3a3`, акцент **`#ff8a1f`**, второй акцент `#ffc37a`, циан `#5ce1e6`, маскот — рыжий кот в робо-костюме.

### Вариант A (по умолчанию): «km-dashboard + оранжевый акцент»
Сохраняем сине-тёмные поверхности km-dashboard (узнаваемый вид), меняем только акцент. Оранжевый на тёмно-синем — контрастно и «технологично».

```css
:root{
  --bg:#0a0f1e; --bg2:#0e1528; --card:#121a30; --card2:#182142; --bd:#253156; --bd2:#31406d;
  --tx:#e8ecf8; --mu:#9aa5c3;
  --ac:#ff8a1f; --ac2:#ffc37a; --ac-contrast:#1a0e02;   /* текст на акцентной кнопке — тёмный */
  --gr:#22c55e; --rd:#ef4444; --yl:#f5b041; --vi:#a78bfa; --cy:#5ce1e6; --pk:#ec4899;
  --rowline:#202b4d; --insbg:#1d1a2a; --insbd:#5a3d22;
  --shadow:0 10px 30px #00000038;
  --glow:radial-gradient(1100px 500px at 12% -8%, #3a2414 0%, transparent 55%);
}
```

### Вариант B: «тёплый тёмный» (как публичный vaybik.ru)
Поверхности в тёплых коричнево-чёрных тонах — админка выглядит одним продуктом с сайтом.

```css
:root{
  --bg:#0e0c0a; --bg2:#141110; --card:#1a1714; --card2:#221d19; --bd:#2f2823; --bd2:#3d342d;
  --tx:#fff8f2; --mu:#c4b3a3; --ac:#ff8a1f; --ac2:#ffc37a; --ac-contrast:#1a0e02;
  --rowline:#26201c; --insbg:#231a12; --insbd:#5a3d22;
  --glow:radial-gradient(1100px 500px at 12% -8%, #3a2414 0%, transparent 55%);
}
```

### Вариант C: оригинальный синий `#2f6bff`
Один в один km-dashboard; оранжевый остаётся только в логотипе.

Светлая тема (`.light`) — как в оригинале (`--bg:#eef1f8; --card:#fff; --tx:#17203a; --mu:#5b6684 …`), акцент `#e8740a` (чуть темнее для контраста на белом).

> Выбор варианта — одна переменная `NEXT_PUBLIC_THEME_VARIANT` / настройка в «Настройках Вайбика». По умолчанию A.
> Важно: на оранжевой кнопке текст тёмный (`--ac-contrast`), белый на `#ff8a1f` не проходит WCAG AA.

## 3. Tailwind

`tailwind.config.ts` (или `@theme` в Tailwind v4) — цвета через CSS-переменные, чтобы тема переключалась классом:

```ts
colors: {
  bg: 'var(--bg)', bg2: 'var(--bg2)', card: 'var(--card)', card2: 'var(--card2)',
  bd: 'var(--bd)', bd2: 'var(--bd2)', tx: 'var(--tx)', mu: 'var(--mu)',
  ac: 'var(--ac)', ac2: 'var(--ac2)', gr: 'var(--gr)', rd: 'var(--rd)', yl: 'var(--yl)',
  vi: 'var(--vi)', cy: 'var(--cy)', pk: 'var(--pk)', rowline: 'var(--rowline)',
  insbg: 'var(--insbg)', insbd: 'var(--insbd)',
},
borderRadius: { xs:'7px', sm:'8px', md:'10px', lg:'11px', xl:'14px', '2xl':'16px' },
fontFamily: { sans: ['Manrope','Segoe UI','Roboto','Arial','sans-serif'] },
boxShadow: { card: 'var(--shadow)' },
```

Шрифт подключать через `next/font/google` (Manrope, subsets `latin`, `cyrillic`).

## 4. Компоненты (`src/components/ui/*`)

| Компонент | Назначение / пропсы |
|---|---|
| `AppShell` | сайдбар + шапка + контент; мобильная версия |
| `Sidebar`, `NavItem` | бренд (кот-маскот 44×44, «Вайбик» / «панель управления»), группы меню, `SideSummary` внизу (например: «Сервисов онлайн 5/6», «Заявок сегодня 12», «Сервер CPU 18%») |
| `Topbar` | LiveDot + «обновлено …», бейдж окружения (prod/dev), `Segmented` период, поиск (Ctrl+K), переключатель темы, меню пользователя |
| `Card`, `CardHeader` (`title`, `subtitle`, `action`) | базовая карточка |
| `Kpi` (`label`, `value`, `delta`, `tone: ok/warn/bad`) | KPI с полоской |
| `Pill` (`tone: green/yellow/red/accent`) | статусы: «онлайн», «деградация», «упал», «новый» |
| `Insight` | вывод/подсказка под блоком |
| `Alert` (`tone`) | «Внимание»: упавшие сервисы, истекающие сертификаты/домены, неудачные бэкапы |
| `DataTable` | сортировка, поиск, пагинация, sticky header, `tabular-nums`, слот для `Sparkline` |
| `Sparkline` | SVG 110×26 |
| `Chart` | обёртка над Chart.js 4 (react-chartjs-2), цвета из CSS-переменных, перерисовка при смене темы |
| `Segmented` | переключатель периода/режима |
| `Field`, `Input`, `Select`, `Textarea`, `Switch`, `SecretInput` (маска + «показать» с повторной аутентификацией) | формы в стиле калькулятора |
| `CalcCard` | форма + крупный результат `.res` (используется в SEO-превью, калькуляторе стоимости для партнёров, оценке бэкапа) |
| `Kanban` | для заявок (lead.vaybik.ru) — по образцу мини-CRM |
| `Button` (`primary/ghost/danger`, `size sm/md`), `ConfirmDialog` (для опасных действий — ввод названия) | |
| `Drawer`/`Modal`, `Tabs`, `EmptyState`, `Skeleton`, `Toast` | |
| `LogViewer` | моноширинный, тёмный, автоскролл, фильтр |
| `StatusDot` | зелёный пульс / жёлтый / красный / серый |

Правила: никаких хардкод-цветов в компонентах — только токены; каждая страница = `h2`-секции из карточек в сетках `k4/k5/g2/g3/g-2-1`; демо-данные всегда помечаются `Pill`/бейджем «демо»; русский интерфейс, числа через `toLocaleString('ru-RU')`, даты `dd.MM.yyyy HH:mm` (Europe/Moscow).
