# Правки для агента чата (этап 2 CLIENT, без кабинета-аналитики)

> Хаб уже выпускает SSO `mode:"client"`, `aud:"chat"`, `impersonatedBy:null`.  
> Код чата в этом PR **не меняли** — ниже минимальный список для агента чата.

## Контракт SSO (уже есть)

Payload без изменений:

`{ iss:"vaybik-hub", aud:"chat", mode:"client"|"impersonate", … }`

При `mode=client`:

- сессия с `ssoMode=client`, `clientId` = клиент чата по `hubClientId`
- `User.role=CLIENT` (уже создаётся в `/sso`)
- чужой clientId → 404 (уже есть)

## Что поменять в чате

1. **Прятать только админское при `ssoMode=client`:**
   - блок **Group Privacy** и любые пояснения про BotFather / privacy бота студии;
   - редактирование тарифа / сроков / `paymentNote` (если где-то есть поля ввода — оставить **только RO-бейдж срока**, как сейчас);
   - прочие студийные/админские настройки, которых нет у клиента.

2. **НЕ прятать:**
   - **`/link` и инструкцию привязки Telegram-группы** — клиент сам подключает группу менеджеров;
   - срок работы виджета (просмотр).

3. **Проверка на сервере:** CLIENT / `ssoMode=client` не должен PATCH-ить запрещённое (часы RO уже есть; добить эндпоинты, где ещё можно править админское).

4. Аналитика / список диалогов / заявки из `docs/plans/2026-11-18-client-cabinet-v1.md` — **не делать** в этой итерации.
